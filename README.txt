BLUE SPACE RUNNER — single-file HTML mini-game

HOW TO PLAY
- Open index.html in a web browser, or use VS Code + Live Server.
- Move the spaceship forward/backward and side to side with W/A/S/D or the arrow keys.
- On phones, use the four directional buttons.
- Collect glowing blue stars. Avoid asteroids.
- Each stage gets harder. The score resets at each stage.
- After every completed stage, you'll get an encouraging message.
- Press P to pause. Toggle sound in the top-right.
